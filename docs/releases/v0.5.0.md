# Frame v0.5.0

Frame v0.5.0 gives each fact one owner. Values that were restated, recomputed
or sequenced by callers now live with the type that owns them: a release is one
manifest, the process driver owns admitted creation, Host restoration confirms
its own projection, and a business owner answers only for the installation it is
asked about. Several changes come from reviewing how Flame uses the module. This
release contains breaking Go API, release-format and protocol changes from
v0.4.0, with no compatibility aliases.

## Requirements

Use the Go minimum in `go.mod` and the Node range in `sdk/package.json`:
Go 1.27.4 or newer and Node 24.22.1 or newer. The optional React entry targets
React 19. Managed local execution requires supported Unix filesystems and sockets.

## Rebuild together

Rebuild the Host, the SDK and every plugin process together:

- The local stdio protocol digest now covers the `hello` description shape, so
  peers built from v0.4.0 refuse the new protocol at hello.
- A release archive is one `manifest.json` and its artifacts. Archives built by
  v0.4.0 carry `plugin.lock.json` and a manifest `release` member, so they are
  refused. Rebuild them with `frame package` or `distribution.Build`.
- A binding's identity document sorts object members, so retained binding
  identities change. Stored attempts must record their scope, scope generation
  and instance generation. Start from fresh development state rather than
  migrating v0.4.0 databases.

## Upgrade from v0.4.0

### Host

| v0.4.0 | v0.5.0 |
| --- | --- |
| `host.SetEnabled(ctx, id, enabled)` | `host.Enable(ctx, id)` or `host.Disable(ctx, id)` |
| `framehost.WithPlan(ctx, host, plan, grant, call)` | `host.WithUse(ctx, grant, plan, call)` |
| `host.Dependency`, `CompactDependencies` | `host.ReleaseRef`, `CompactReleases` |
| `ExportRef.Unit()`, `UnitRef.Dependency()` | the embedded `UnitRef` and `ReleaseRef` fields |
| `BindingSnapshot.CanonicalJSON() ([]byte, error)` | `BindingSnapshot.Canonical() (value.JSON, error)` |
| `UseOwner.Held` returning `[]Dependency` | `UseOwner.Held` returning the queried installation's `[]value.Digest` |
| a hand-built `ContractRef` passed to `BindContract` | `host.NewDescriptorContract[T](name, version, descriptor)` |

`UnitRef` embeds `ReleaseRef` and `ExportRef` embeds `UnitRef`. Composite
literals that name the promoted fields still compile, and their JSON shapes are
unchanged. `BindContract` remains the verifier of a received `ContractRef`.

`Host.Restore` now confirms its projection through
`InstallationStore.ConfirmRestoredInstallations`. Remove the call to
`sqlite.Store.ConfirmRestoredInstallations` that followed restoration; a custom
installation store implements the new method.

### Process

`process.Driver` queues admitted creations itself and joins a dispatched
`Runner.Launch` instead of cancelling it. Remove application `Runner` wrappers
that serialized launches or detached their context. A `Runner` given a done
context must not dispatch. `process.Protocol.Prepare` names its frame limit
`maxFrameBytes`; a custom protocol reporting `local-process` owns that limit.

`process/mcp` drops the managed profile (`ManagedProtocol`, `ManagedProfile`,
`ManagedExport`, `ManagedContract`, `ParseManagedContract`, `ManagedCallback`,
`CallbackReceiver`, `WithInvocation` and related types). Implement an
application MCP protocol over `process.Protocol` and `mcp.Transport`.
`mcp.Tools.Result` returns `StructuredResult` or `EnvelopeResult` in place of
the boolean `FullResult`.

### Distribution

| v0.4.0 | v0.5.0 |
| --- | --- |
| `Build(...) (Lock, error)` | `Build(...) (Release, error)` |
| `Trust func(ctx, Source, Manifest, Lock) error` | `Trust func(ctx, Source, Release) error` |
| `Manifest.Release`, `Lock`, `LockName`, `ParseLock`, `Manifest.Lock` | `Manifest.Identity()` or `Release.Digest` |
| `LockedRelease` | `Dependency` |
| `ImportDirectoryHeld`, `ImportArchiveHeld` | `ImportDirectory`, `ImportArchive`, which return the holding `Lease` |
| `Limits.Entries`, `ExpandedBytes`, `ArchiveBytes`, `ManifestBytes`, `CompressionRatio` | the same fields with a `Max` prefix |

`Manifest.Canonical` returns a `value.JSON`. `frame package` reports
`archiveDigest`, `releaseDigest` and `manifest`, the vocabulary of `frame inspect`.

### SQLite

| v0.4.0 | v0.5.0 |
| --- | --- |
| `sqlite.Connection(ctx, db)` | `db.Executor(ctx)` |
| `sqlite.RunInTx`, `RunReadSnapshot`, `RunIndependentTx`, `InstallSchema` | methods of `sqlite.Database` with the same names |
| `OwnerSchema.References` returning `[]host.Dependency` | `OwnerSchema.References` returning `[]value.Digest` |
| an attempt assembled by each driver | `sqlite.NewAttempt(setup, realm)` |

`Attempt.Parent` is removed.

### Browser, contracts and values

| v0.4.0 | v0.5.0 |
| --- | --- |
| `browser.RealmID(realm)` | `realm.HostRealm()` |
| `contractgen.Generate(source, artifacts, typescript, outputs...)` | `contractgen.Generate(contractgen.GenerateConfig{...})` |
| `value.TypeString` and other schema constants | `value.SchemaTypeString`, `SchemaChildrenMap`, `SchemaEdgeSame`, `SchemaValueString` and so on |
| `PortableProfileLimits.MaxTokenBytes` | removed |

`browser.BridgeConfig.MaxRoutes` bounds Realm event routes, and
`browser.HTTPEnvelope.Input` is a `jsontext.Value`. `value.JSON.Decode`
replaces hand-written `RejectUnknownMembers` and `value.Numbers` options when
decoding an admitted value. `@frame/sdk/json` adds `projectNumbers` and
`ProjectedJSONValue` for authoring schemas that consume plain numbers.

The complete list is in the [changelog](../../CHANGELOG.md).

## Install

```sh
go get github.com/Tangerg/frame@v0.5.0
go install github.com/Tangerg/frame/cmd/frame@v0.5.0
go install github.com/Tangerg/frame/cmd/frame-runner@v0.5.0
npm install ./frame-sdk-0.5.0.tgz
```

Download the SDK tarball and original Chinese design proposal from the GitHub
release and verify them against its `SHA256SUMS`. The SDK keeps the existing
native, Node, browser and React entry points. Release versions are coordinated;
protocol and contract identities remain independent of those version numbers.
