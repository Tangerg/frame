# Frame v0.4.0

Frame v0.4.0 separates calling-owner evidence from MCP execution. Protocol,
domain and delivery consumers can use the pure `call` package without importing
transport or callback capabilities. This release contains breaking Go API changes
from v0.3.0 and keeps application policy with its consumer.

## Requirements

Use the Go minimum in `go.mod` and the Node range in `sdk/package.json`:
Go 1.27.4 or newer and Node 24.22.1 or newer. The optional React entry targets
React 19. Managed local execution requires supported Unix filesystems and sockets.

## Upgrade from v0.3.0

Import `github.com/Tangerg/frame/call` for the following values:

| v0.3.0 | v0.4.0 |
| --- | --- |
| `mcp.Invocation` | `call.Invocation` |
| `mcp.Target` | `call.Target` |
| `mcp.Origin` | `call.Origin` |
| `mcp.ErrInvocationConflict` | `call.ErrConflict` |
| `mcp.Refusal` | `call.Refusal` |
| `mcp.InvocationConflictCode` | `call.ConflictCode` |

`mcp.WithInvocation` remains in the execution adapter and accepts
`call.Invocation`. Remove former imports where no execution adapter is needed.
There are no compatibility aliases or duplicate value definitions.

Calling evidence grants no authority. A refusal value alone cannot prove that a
remote invocation settled. The original MCP reply continues to own that outcome
proof; callback, local cancellation and transport errors cannot manufacture it.
Resource retirement and business settlement remain with their original owners.

JSON fields and validation are unchanged. Generated schema definition names can
include the Go package path, so regenerate contracts and rebuild their consumers
together. Those definition and reference changes can change an exact contract
identity even when its admitted business payload is equivalent. Do not replace
an original retained identity with a regenerated one during replay.

This release changes no Frame stdio/browser protocol declaration or private
persisted format from v0.3.0. Application schemas and any changed contract
identities remain the application's responsibility.

## Application protocols

Current Flame owns its MCP business protocol and its `process.Protocol` adapter.
It is distinct from Frame's optional Qimu managed profile. The qualification
workflow pinned to Flame's former Qimu checkout has been removed. Application
protocol tests belong with the application; Frame retains its independent Go
module, packed SDK, generic Go/Node and MCP profile checks.

## Install

```sh
go get github.com/Tangerg/frame@v0.4.0
go install github.com/Tangerg/frame/cmd/frame@v0.4.0
go install github.com/Tangerg/frame/cmd/frame-runner@v0.4.0
npm install ./frame-sdk-0.4.0.tgz
```

Download the SDK tarball and original Chinese design proposal from the GitHub
release and verify them against its `SHA256SUMS`. The SDK keeps the existing
native, Node, browser and React entry points. Release versions are coordinated;
protocol and contract identities remain independent of those version numbers.
